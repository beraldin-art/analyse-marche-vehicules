#  Analyse du marché des véhicules d'occasion

##  Contexte

Ce projet a été réalisé dans le cadre d’un projet data visant à analyser le marché des véhicules d’occasion dans la région lilloise.
L’objectif est d’aider un réseau de concessionnaires à mieux comprendre les prix du marché et le comportement des vendeurs.

---

##  Objectifs

* Nettoyer et transformer des données brutes issues d’annonces automobiles
* Concevoir un modèle de données en étoile
* Réaliser des analyses SQL
* Construire un tableau de bord décisionnel

---

##  Outils utilisés

* Python (PySpark)
* SQL
* Databricks
* Power BI

---

##  Architecture du projet

* Ingestion des données (CSV → Databricks)
* Transformation et nettoyage (SQL / PySpark)
* Création d’une table analytique
* Visualisation avec Power BI

---

##  Analyses réalisées

* Prix moyen des véhicules par marque et motorisation
* Répartition des annonces entre professionnels et particuliers
* Analyse du marché par tranche de kilométrage

---

##  Résultats & insights

* Les véhicules diesel ont un prix moyen plus élevé que les véhicules essence
* Le marché est dominé par les vendeurs professionnels
* Les véhicules à fort kilométrage sont majoritaires

---

##  Recommandations

* Prioriser les véhicules diesel pour améliorer la rentabilité
* Adapter la stratégie de prix face à la dominance des professionnels
* Se positionner sur les segments de kilométrage les plus représentés
